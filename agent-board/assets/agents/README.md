# Agent avatars

The agent artwork is derived from the open-source
[alvinunreal/oh-my-opencode-slim](https://github.com/alvinunreal/oh-my-opencode-slim)
repository:

- `orchestrator.jpg`, `explorer.jpg`, `fixer.jpg`, `designer.jpg`, `oracle.jpg`, `observer.jpg`
- `arbiter.webp`, `paladin.webp`, `proctor.webp`, `hunter.webp` from `img/marketplace/`

The files under `thumb/` are cropped and resized to 128×128 for the panel.
`unknown.svg` is an original placeholder for `build`, `plan`, and unknown agents.

If this panel is published as a separate open-source project, keep this
attribution and verify the upstream license and artwork terms before release.
